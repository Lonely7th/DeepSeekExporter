Microsoft Edge

三分钟安装
DeepSeek Exporter

通过 Microsoft Edge 官方扩展商店安装，无需下载未知文件。安装后直接在 DeepSeek 网页中导出对话。

前往 Edge 扩展商店 ↗

安装前确认

  • 使用 Microsoft Edge 88 或更高版本。
  • 能够正常访问 DeepSeek 网页并登录账号。
  • 建议从官方商店页面安装，核对开发者为“鲸鱼AI助手”。

安装步骤

1. 打开 Edge 扩展商店

点击本页的“前往 Edge 扩展商店”，进入 DeepSeek-Exporter AI 对话导出工具详情页。

2. 点击“获取”

在商店页面点击“获取”，浏览器弹出权限说明后选择“添加扩展”。安装完成后会出现成功提示。

3. 固定到工具栏

点击地址栏右侧的扩展按钮，在 DeepSeek Exporter 旁选择固定。这样可以随时打开偏好设置。

4. 完成第一次导出

访问 chat.deepseek.com，打开任意对话，将鼠标移到回答操作区，点击导出按钮并选择 Word、PDF 或其他格式。

看不到导出按钮怎么办？

  • 刷新 DeepSeek 页面，确认扩展已启用。
  • 在 edge://extensions 中检查插件开关。
  • 如果 DeepSeek 页面刚更新，尝试关闭其他同类扩展后重试。
  • 仍未解决时，通过官网帮助入口反馈浏览器版本和问题截图。

准备好了吗？
