# DeepSeek Exporter

一款面向 DeepSeek 网页端的浏览器扩展，可以将 DeepSeek 对话导出为 Word、PDF、Markdown、HTML、JSON、Jupyter Notebook 等格式。

完整保留标题层级、代码高亮、Markdown 表格和 LaTeX 数学公式，适合整理学习笔记、技术文档、研究资料和工作报告。

- 官方网站：[https://www.aibusgo.com/](https://www.aibusgo.com/)
- 使用指南：[https://www.aibusgo.com/guide/](https://www.aibusgo.com/guide/)
- 版本更新：[https://www.aibusgo.com/changelog/](https://www.aibusgo.com/changelog/)

## 主要功能

- 将 DeepSeek 对话导出为多种常用格式
- 保留标题、列表、引用和段落结构
- 保留代码块及语法高亮
- 支持 Markdown 表格
- 支持 LaTeX 数学公式
- 支持单条回答或完整对话导出
- 在浏览器本地完成内容整理
- 支持 Chrome、Edge、Firefox 及兼容 Chromium 的浏览器

## 支持的导出格式

| 格式 | 适用场景 |
| --- | --- |
| Word | 报告、论文素材、会议记录和可编辑文档 |
| PDF | 打印、归档和稳定分享 |
| Markdown | Obsidian、知识库和技术写作 |
| HTML | 网页发布和内容预览 |
| JSON | 数据处理和二次开发 |
| Jupyter Notebook | 编程、研究和数据分析 |
| 其他格式 | 以当前扩展版本实际提供的选项为准 |

## 使用方法

1. 安装对应浏览器版本的扩展。
2. 打开 DeepSeek 网页端并进入需要保存的对话。
3. 点击浏览器工具栏中的扩展图标。
4. 选择单条回答或完整对话。
5. 选择 Word、PDF、Markdown 或其他输出格式。
6. 生成并下载文件。

## 隐私说明

DeepSeek Exporter 重视用户对话内容的隐私。

扩展的格式整理和导出过程在浏览器端完成，不需要为了生成文档而把完整对话上传到第三方转换服务器。具体权限、数据处理方式和最新隐私政策，以官方网站和浏览器扩展商店中的说明为准。

使用扩展前，请避免在对话中包含密码、访问令牌、身份证件、未公开商业资料等敏感信息。
