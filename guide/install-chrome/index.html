Google Chrome

在 Chrome 安装
DeepSeek Exporter

从 Chrome 应用商店添加插件，固定到工具栏后即可在 DeepSeek 网页中导出 Word、PDF、Markdown 等格式。

前往 Chrome 应用商店 ↗

安装步骤

  1. 使用 Chrome 88 或更高版本打开官方商店页面。
  2. 点击“添加至 Chrome”，阅读权限说明后确认。
  3. 点击浏览器右上角拼图图标，将 DeepSeek Exporter 固定到工具栏。
  4. 刷新已经打开的 DeepSeek 页面，进入对话并点击导出按钮。
商店无法访问？不要从不明下载站获取扩展安装包。可以改用 Microsoft Edge、360 或 Firefox 的官方商店版本，或通过产品官方离线安装入口获取说明。

第一次导出

打开一条包含公式、代码或表格的对话，选择 Word 格式测试排版；如果只需要归档分享，可以直接选择 PDF。

关于扩展权限

浏览器扩展需要在 DeepSeek 页面运行才能识别对话内容并显示导出按钮。请始终以商店展示的权限和隐私声明为准；敏感内容建议启用无痕模式并只选择必要的回答。

如何保持最新版？

通过 Chrome 应用商店安装的扩展会由浏览器自动更新。也可以在 chrome://extensions 开启开发者模式后点击“更新”检查版本。

从 Chrome 商店安装

安装完成后，刷新 DeepSeek 页面即可使用。
